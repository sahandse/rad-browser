# RAD Browser — راد

مرورگر Flutter برای Android و Web با تمرکز بر تجربه کاربری مینیمال، سریع و دسترسی هوشمند به وب و شبکه داخلی.

## وضعیت پروژه

در حال توسعه — مرحله ۱: اسکلت Flutter، Design System و Home اولیه.

## اهداف اصلی

- رابط کاربری مینیمال با الهام از مرورگرهای مدرن
- Android + Web/PWA
- تشخیص سه حالت شبکه: اینترنت کامل، شبکه داخلی، آفلاین
- دایرکتوری آفلاین سایت‌های ایرانی
- تب‌ها، تاریخچه، بوکمارک و دانلودها
